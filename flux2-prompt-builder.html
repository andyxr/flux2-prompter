FLUX.2 Prompt Builder [pro·max·flex·klein]

Assemble a FLUX.2 prompt in the order the model weighs it: subject first, then how each reference image is used, then style, context, camera, text and exact colours. Add reference images to get image 1, image 2… labels you can drop into any field.

SETUP

Model and output size

The model sets how many references you can attach. Output size isn't part of the prompt text; it goes in the API or node settings.
INPUTS

Reference images

Order matters: image 1 is the first input you attach, image 2 the second, and so on. Give each a role and the tool writes a sentence saying how it's used.

Thumbnails are optional and stay in this browser tab; they help you keep track of which picture is which number.

1 · SUBJECT + ACTION

Main subject

FLUX.2 pays most attention to what comes first, so lead with the main subject and what it's doing.
2 · STYLE

Style and medium

Name the medium or photographic look. Presets from BFL's style guide append their descriptors.
3 · CONTEXT

Setting, light and mood

Where it happens and how it feels. Leave anything blank to skip it.
4 · CAMERA

Camera and lens

For photoreal work, "Shot on Fujifilm X-T5, 35mm f/1.4" beats "professional photo".
5 · TEXT

Text in the image

Each line is quoted exactly. Say where it sits, how big, what lettering and which colour.
6 · COLOUR

Exact colours

Tie every hex code to a specific object. Add a second hex to make it a gradient.
7 · PRESERVE + DETAILS

What stays, and the finishing details

For edits, say plainly what must not change. Secondary details go last because they carry the least weight.
